# Discipline

Приложение для саморазвития: задачи, недельное расписание, привычки, цели и заметки — в одном окне.

## Как запустить

Просто открой `index.html` двойным кликом. Никаких установок, сборки и интернета не нужно.

Если хочешь запустить через локальный сервер (например, чтобы открыть с телефона в той же сети):

```powershell
cd selfdev
python -m http.server 8000
```

Затем открой http://localhost:8000

## Разделы

| Раздел | Что делает |
|---|---|
| **☀️ Сегодня** | Дашборд: задачи на сегодня, занятия по расписанию (с подсветкой «сейчас»), привычки в один клик, ближайшие цели |
| **✅ Задачи** | Todo с приоритетами, сроками, проектами и заметками. Фильтры: активные / сегодня / 7 дней / просроченные / выполненные |
| **🗓️ Расписание** | Повторяющаяся неделя. Клик по пустому месту в дне — добавить занятие, клик по занятию — изменить |
| **🔥 Привычки** | Отметки по дням недели, стрик (сколько дней подряд) и процент за 30 дней. Можно задать, в какие дни привычка активна |
| **🎯 Цели** | Долгосрочные цели с дедлайном, шагами и полосой прогресса (считается по шагам) |
| **📝 Заметки** | Дневник и идеи с поиском |
| **⚙️ Настройки** | Имя, тема, экспорт/импорт JSON, статистика, полная очистка |

## Горячие клавиши

- `1`–`7` — переключение между разделами
- `N` — создать запись в текущем разделе
- `Esc` — закрыть окно

## Где хранятся данные

В `localStorage` браузера, только на твоём компьютере — ничего никуда не отправляется.

⚠️ Чистка истории браузера или режим инкогнито могут стереть данные. **Настройки → Скачать JSON** делает резервную копию; **Загрузить из файла** восстанавливает её (и переносит данные на другой компьютер).

## Структура

```
selfdev/
├── index.html          # разметка всех экранов
├── css/styles.css      # тема (тёмная/светлая), вёрстка, адаптив
└── js/
    ├── store.js        # localStorage, CRUD, подписка на изменения
    ├── ui.js           # даты, склонения, модалка, тосты
    ├── tasks.js        # задачи
    ├── schedule.js     # расписание
    ├── habits.js       # привычки и стрики
    ├── goals.js        # цели и шаги
    ├── notes.js        # заметки
    ├── today.js        # дашборд
    └── app.js          # роутинг, тема, бэкап, запуск
```

Любое изменение данных проходит через `Store.commit()`, который сохраняет в localStorage и перерисовывает активный экран — отдельно синхронизировать интерфейс не нужно.
